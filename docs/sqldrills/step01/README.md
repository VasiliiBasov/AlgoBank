# Шаг sql-01 — базовый SELECT (12 задач)

**Цель:** уверенно писать `SELECT/WHERE/ORDER BY` без гугла. Это минимум, который
спрашивают на любом junior-собесе (EGAR: «SQL (SELECT, JOIN)»).

## Схема (из миграции V1)

```sql
account      (id BIGINT PK, owner_name VARCHAR, balance_minor BIGINT)
transactions (id BIGINT PK, amount_minor BIGINT, description VARCHAR NULL,
              account_id BIGINT FK -> account.id)
```

Суммы — в минорных единицах (копейки): 150000 = 1500.00 ₽.

## Шпаргалка-минимум (без ответов на задачи)

```sql
SELECT [DISTINCT] col, expr AS alias FROM table
WHERE cond1 AND cond2          -- =, !=, <, >, BETWEEN a AND b (включительно),
                               -- IN (...), LIKE 'текст%' (% — любой хвост),
                               -- IS NULL / IS NOT NULL (только так, не = NULL!)
ORDER BY col [ASC|DESC], col2  -- ASC по умолчанию
LIMIT n;
```

## Задачи

Правила: **один `SELECT` на файл**, без подзапросов; порядок строк важен — сверяй точно.
Файл: `src/main/resources/sqldrills/step01/qNN.sql`.

### Q4 — `q04.sql`
