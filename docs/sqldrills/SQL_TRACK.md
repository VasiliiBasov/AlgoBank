# 🗄 SQL-трек AlgoBank

> Параллельный мини-трек: закрывает пробел «SQL на собеседовании», выявленный
> mock-интервью 25.09 (вопрос 10 — 20/100: перепутан INNER/LEFT, запрос не написан).
> Требования вакансий: EGAR — «SQL (SELECT, JOIN)»; СПИИРАН — «реляционная модель, базовый синтаксис SQL».

## Принципы (те же, что в algo-потоке)

- **SQL пишет только ученик** (правило №5 хендбука). Ментор: постановки, фикстуры, разбор, ревью, зачёт.
- Один вечер = 20–30 минут SQL. Трек **не подменяет** основной шаг курса (сейчас — шаг 7).
- Формат приёмки: самопроверка по ожидаемым таблицам → ревью запросов ментором → устный мини-зачёт.

## Где что лежит

```
src/main/resources/
├── application-sqldrill.yml      ← профиль трека: своя H2 + сид-данные
└── sqldrills/
    ├── seed/V900__sqldrill_seed.sql   ← фикстуры (Flyway, только в профиле sqldrill)
    └── step01/q01.sql … q12.sql       ← РЕШАЕТ УЧЕНИК (один SELECT на файл)
docs/sqldrills/
├── SQL_TRACK.md                  ← этот файл
└── step01/README.md              ← теория-минимум + 12 постановок + ожидаемые результаты
```

## Как работать

```powershell
# 1. Поднять приложение в профиле sqldrill
mvn spring-boot:run "-Dspring-boot.run.profiles=sqldrill"

# 2. H2 console: http://localhost:8082/h2-console
#    JDBC URL: jdbc:h2:mem:sqldrills   User: sa   Password: (пусто)

# 3. Пишешь запрос в src/main/resources/sqldrills/step01/qNN.sql,
#    прогоняешь в консоли, сверяешь с ожидаемой таблицей из README задачи.
```

## Карта трека

| Шаг | Темы | Статус |
|-----|------|--------|
| **sql-01** | `SELECT`, `WHERE`, `ORDER BY`, `DISTINCT`, `LIMIT`, `IN`, `BETWEEN`, `LIKE`, `IS NULL`, алиасы, арифметика | 🟡 материалы готовы, ждёт решения |
| **sql-02** | `INNER JOIN` vs `LEFT JOIN` (счета без транзакций!), NULL при JOIN, несколько JOIN | ⬜ |
| **sql-03** | `GROUP BY`, `COUNT/SUM/AVG/MIN/MAX`, `HAVING`, простой подзапрос | ⬜ |
| **jdbc-harness** (опц., после зачёта шага 7) | ученик строит JUnit-прогонщик qNN.sql на чистом JDBC — заодно тема JDBC для собеса | ⬜ |

## Оценка шага

- 12 задач, балл = число подтверждённых ревью верных запросов × 8 (96) + зачёт (4 вопроса × 1).  
  Шаг зачтён при **≥ 10/12 задач** и **зачёт ≥ 80/100**.
- Провалы зачёта → в ротацию разминок, как обычно.
